# 삼국 패왕전

삼국지를 소재로 한 90년대 오락실 감성의 **벨트스크롤 액션 게임**입니다.
설치 없이 `index.html` 하나로 브라우저에서 바로 실행됩니다. PC 키보드와 휴대폰 터치를 모두 지원합니다.

## 실행 방법
- `index.html`을 브라우저로 열면 됩니다.
- GitHub Pages를 켜면 웹 주소로 바로 플레이할 수 있습니다. (Settings → Pages → Branch: `main` / root)

## 조작
| 동작 | 키보드 | 터치 |
|---|---|---|
| 이동 | 방향키 / WASD | 방향 패드 |
| 공격 (연타 시 3단 콤보) | Z | 공격 |
| 점프 (공중에서 공격 = 내려찍기) | X / Space | 점프 |
| 필살기 | C (또는 공격+점프) | 필살 |

필살기는 기 게이지가 가득 차면 게이지를 쓰고, 아니면 체력을 조금 소모합니다.

## 장수
| 장수 | 무기 | 필살기 |
|---|---|---|
| 관우 | 청룡언월도 · 한 방이 무거움 | 화룡참 – 앞으로 뻗는 불길 |
| 장비 | 장팔사모 · 긴 사거리 | 대지진 – 주변 충격파 |
| 조운 | 창 · 빠른 연타 | 백룡돌격 – 빛의 돌진 |

## 스테이지
1. **황건의 난** – 보스 장각 (낙뢰 요술)
2. **호로관** – 보스 여포 (돌진, 방천화극)
3. **적벽대전** – 보스 조조 (화살비, 호위병 소환)

항아리를 깨면 만두(체력 회복)나 금(점수)이 나옵니다. 목숨은 3개, 다 잃으면 컨티뉴할 수 있습니다.

## 기술
- HTML5 Canvas, 순수 JavaScript (라이브러리 없음)
- 캐릭터·배경 그래픽은 모두 코드로 그린 도트 스타일
- 음악·효과음은 Web Audio API 칩튠

이미지·음원 파일 없이 모든 그래픽과 사운드를 코드로 생성합니다.
